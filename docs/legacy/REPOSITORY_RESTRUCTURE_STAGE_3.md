# MansooriKart Repository Restructure — Stage 3

## Scope and deletion rule

Stage 3 performed only evidence-backed cleanup. Every removed dependency had no active import, dynamic import, configuration, script, test, Docker, Compose, or CI reference. Legacy `/api/*`, MUI/Emotion, the Stage 2 Docker configuration, active CI workflow, Kubernetes archive, and all AI/vector code were protected.

## Dependency cleanup

- Root: `bcryptjs`, `jsonwebtoken`, `mongoose` — backend-only packages already owned by `backend/`.
- Frontend: `@pmmmwh/react-refresh-webpack-plugin`, `@react-buddy/ide-toolbox`, `@react-buddy/palette-mui`, `@stripe/react-stripe-js`, `@stripe/stripe-js`, `react-credit-cards-2`, `react-hook-form`, `web-vitals`, and `zod`.
- Backend: `concurrently` and `http-proxy-middleware`.

### Development dependencies removed

- Root: `supertest` — backend test tooling is owned by `backend/`.
- Frontend: `css-loader` and `style-loader`.

The root workspace now owns only orchestration and shared formatting dependencies. The root lockfile was refreshed without a package upgrade, then validated by a fresh `npm ci --ignore-scripts` installation and `npm ls --depth=0`.

`react-material-ui-carousel` remains because a current snapshot test mocks/resolves it. MUI has 25 active frontend importing files; Emotion remains as MUI's styling peer dependency despite no direct Emotion import.
