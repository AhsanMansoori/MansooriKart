# Historical Kubernetes archive

The manifests and scripts in this directory are historical Fusion-era infrastructure. They are not current MansooriKart production infrastructure, deployment instructions, or evidence of a running Kubernetes deployment.

They are retained only for reference. Before any future Kubernetes deployment, these files must be redesigned for the selected platform and undergo a new security review covering images, networking, certificates, secrets, observability, deployment strategy, and operational ownership.

The archived Secret resource is a placeholder template. The Stage 2 archival inspection found no literal secret values, tokens, database URIs, private registry credentials, or certificates in the Kubernetes material.
